# Русификатор Vectric Aspire 12.5

Полный русский перевод интерфейса Vectric Aspire 12.5 (12.5.0.4) с графическим установщиком.
Делает **A&A — мастерская форм** ([aa-forma.ru](https://aa-forma.ru)). Бесплатно, не продаётся.

**Скачать:** раздел [Releases](../../releases) — последняя версия всегда сверху.
Новости и обсуждение: [группа VK](https://vk.com/club242105697), [Telegram](https://t.me/aa_forma).

## Что ставит

| Компонент | Что внутри | По умолчанию |
|---|---|---|
| Меню, окна и сообщения | Дополнен перевод ≈1 700 строк, исправлено ≈1 400 ошибочных («Подача» вместо «Холостой ход» и т. п.) | всегда |
| Справка по F1 | 246 страниц на русском, поиск по справке, переведённые скриншоты | ✔ |
| Материалы и база фрез | Названия текстур («Дуб светлый», «Латунь») и групп фрез («Концевые», «МДФ»). Ваши собственные фрезы не трогаются | ✔ |
| Ярлык на рабочем столе | «Aspire (RU)» — запуск сразу на русском | ✔ |

Перед изменениями установщик сохраняет оригинальные файлы. Кнопка **«Удалить русификацию»**
в том же установщике возвращает всё как было. Программа, лицензия и проекты не затрагиваются.

## Требования

- Vectric Aspire **12.5** (перевод сделан под сборку 12.5.0.4), установленный в `C:\Program Files\Aspire 12.5`.
- 64-битная Windows 7 / 8 / 10 / 11 — такая же, как нужна самому Aspire. 32-битной версии нет и не будет.
- Если рядом стоят другие версии Aspire (9.5, 10.5…), установщик их не трогает.

## Установка

1. Скачайте `Aspire_RU_Setup_vX.Y.Z.zip` из [Releases](../../releases), распакуйте.
2. Закройте Aspire, запустите `Aspire_RU_Setup_vX.Y.Z.exe`, отметьте нужные компоненты, «Установить».
3. Запускайте Aspire ярлыком «Aspire (RU)» или как обычно.

**Windows может предупредить** — установщик без цифровой подписи. SmartScreen: «Подробнее» →
«Выполнить в любом случае». Если Защитник заблокировал файл: «Безопасность Windows» → «Журнал защиты» →
эта запись → «Разрешить на устройстве». Ссылка на отчёт VirusTotal есть в описании каждого релиза.

## Известные особенности

- **«Local» в списке систем координат** остаётся по-английски на системах с кодировкой cp1251 — так устроена
  загрузка этого файла в Aspire, перевод этой строки роняет программу при запуске.
- **Названия слоёв, листов и уровней в чужих проектах** («Sheet 1», «Level 1», «Tabs») не переводятся —
  они хранятся в самом файле проекта, Aspire их не локализует. В новых проектах всё на русском.
- **«База инструментов открыта только для чтения»** — начиная с 2.6.5 установщик сам возвращает права на
  папку с базой фрез; запускать Aspire от администратора не нужно.

## Гаджеты на русском

Отдельный установщик `Aspire_RU_Gadgets_Setup` ставит 24 гаджета Aspire 12.5 с переведёнными окнами,
подсказками, сообщениями и схемами (логика скриптов не менялась): 9 встроенных в Aspire заменяются на
месте с копией оригиналов, 15 из [библиотеки Vectric](https://www.vectric.com/gadgets) и Simple Box Creator 12.6
ставятся в общую папку гаджетов. Гаджеты выбираются галочками, убираются той же программой.
Пункты меню «Гаджеты» в Aspire берутся из имён папок и остаются английскими. Код — в `gadgets-installer/`.

## Что в репозитории

Здесь **код установщика и инструменты сборки**: `installer/` и `gadgets-installer/` (Go, без внешних зависимостей, своя GDI-отрисовка),
скрипты пересборки ресурсов (`apply.py`, `mo.py`, `pe.py`, `res.py`, `sign.py`, `autofit.py`), `brand/` (иконки,
сведения о версии).

**Файлов перевода в репозитории нет** — переведённая `Resources_RUS.dll`, `.mo`-файлы, справка и гаджеты являются
производными от файлов Vectric и распространяются только внутри готового установщика в Releases.
Поэтому собрать установщик из репозитория «как есть» нельзя; он собирается из полного дерева,
которое хранится у авторов.

Сборка (для справки):

```
cd installer
GOOS=windows GOARCH=amd64 go build -trimpath -buildvcs=false -ldflags "-s -w -H windowsgui" -o Aspire_RU_Setup.exe .
```

Используется Go 1.20 — последний с поддержкой Windows 7. Одинаковый исходник даёт одинаковый exe байт в байт;
хеши выложенных файлов — в описании релизов.

## Ветки

- `main` — то, что выложено людям.
- `gadget` — гаджет «Конструктор коробок» (Simple Box Creator 12.6 с русским переводом, с разрешения автора
  [gremlin529](https://github.com/gremlin529/Vectric-Box-Gadget)). Пока не дотестирован.
- `dark` — тёмная тема Aspire. 2D-вид тёмным сделать нельзя без правки программы, поэтому отложено.
