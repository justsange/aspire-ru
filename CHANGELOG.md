# Русификатор Vectric Aspire 12.5 — история версий

Ветки: `main` — что выложено людям; `gadget` — конструктор коробок (Simple Box Creator 12.6 RU);
`dark` — тёмная тема. Сборка: `GOOS=windows GOARCH=amd64 go build -trimpath -buildvcs=false -ldflags "-s -w -H windowsgui"`
в папке installer (ветка gadget — с `-tags box`, ветка dark — с `-tags dark`).

## Гаджеты v1.0 — 2026-11-06 (отдельный установщик Aspire_RU_Gadgets_Setup)
- 24 гаджета Aspire 12.5 на русском: 9 встроенных (ProgramData\Vectric\Aspire\V12.5\Gadgets, замена на месте с копией оригиналов в _RU_backup_original) и 15 из библиотеки Vectric + Simple Box Creator 12.6 (Public\Documents\Vectric Files\Gadgets\Aspire V12.5).
- Перевод от подписчика проверен: код Lua сверен с оригиналами Vectric (меняются только строки и комментарии), синтаксис проверен загрузчиком Lua 5.3, допереведены 32 фразы и заголовки окон, единая терминология («косточки», «глубина реза», «подача врезания»), переведены схемы (Chamfer, Fluter, Box Creator).
- Установщик: поиск Aspire по всем дискам и реестру, ручной выбор папки, выбор гаджетов галочками с описанием, «Выбрать все / Снять все», удаление с возвратом оригиналов, права на папку настроек (как в 2.6.5), журнал в %LOCALAPPDATA%\aa-forma.
- Сборка Go 1.20 (Windows 7+), без сторонних библиотек.

## 2.6.6 — 2026-11-03
- Aspire на другом диске или в нестандартной папке: установщик ищет его по всем локальным дискам
  (корень, Program Files, Vectric, Programs, Soft…) и по записи в списке установленных программ.
- Кнопка «Указать папку…» на первом экране — выбрать папку Aspire вручную (проверяется наличие x64\Aspire.exe
  и Language). Указанная вручную папка считается целевой даже без «12.5» в имени.
- Версия для путей в ProgramData берётся из имени папки, иначе 12.5.

## 2.6.5 — 2026-11-03
- Новый шаг установки «Возвращаем права на базу фрез и настройки Aspire»: группе «Пользователи»
  даётся право изменять ProgramData\Vectric\Aspire\V12.5 (icacls, SID S-1-5-32-545), снимается
  атрибут «только чтение». Лечит «База инструментов открыта только для чтения» без запуска Aspire
  от администратора. Выполняется всегда, при удалении русификации не откатывается.
- Остальное — как в 2.6.4.

## 2.6.4 — 2026-11-02 (не публиковалась, заменена 2.6.5)
- Совместимость с Windows 7 x64: установщик собран Go 1.20 (последний компилятор с поддержкой Windows 7),
  вызовы, которых нет до Windows 10 (масштабирование DPI, тёмный заголовок окна), пропускаются.
- Сборка: `GOOS=windows GOARCH=amd64 go1.20 build -trimpath -buildvcs=false -ldflags "-s -w -H windowsgui"`.
  Go 1.20.14 собирается из исходников (github.com/golang/go, тег go1.20.14) любым Go ≥ 1.17.
- 32-битной Windows нет и не будет: Aspire 12.5 только 64-битный.
- Перевод и остальное — как в 2.6.3.

## 2.6.3 — 2026-10-31 (опубликована)
- Исправлено: при нескольких версиях Aspire на компьютере перевод ставится только в 12.5.
  Раньше файлы 12.5 попадали в 9.5/10.5 и те не запускались («Failed to find 'TOOLBOX_TAB_WIDTH='»).
- Галочка «Починить другие версии Aspire» — возвращает им родные файлы из нашей копии.
- Из 2.6.1/2.6.2 (не публиковались): база фрез и материалы, список шагов установщика с галочками,
  подгонка обрезанных надписей (панель визуализации, «Форма: …»), «Ультра» вместо второго «Максимума».
- Гаджет «Конструктор коробок» в сборку не входит (ветка gadget).

## 2.1.1 — 2026-10-31 (патч байтами поверх 2.1, без пересборки)
- Поиск только папки «Aspire 12.5*», подпись «v2.1.1». 73 изменённых байта. Исходников нет — только exe.

## 2.1 — 2026-10-26 (опубликована в VK/Telegram)
- Варианты DLL под кодировку системы (cp1251 / UTF-8 / английские списки) — исправлены кракозябры в списках.
- Ошибка с несколькими версиями Aspire есть во всех версиях до 2.6.3 (включая 2.1).
- Исходники этой версии не сохранились, есть только exe (releases/v2.1).

## Сборка и контроль
- Собирать с `-buildvcs=false`: тогда одинаковый исходник даёт одинаковый exe байт в байт.
- Хеши выложенных файлов — в releases/<версия>/sha256.txt на диске Z (Z:\Claude\aspire-ru).
